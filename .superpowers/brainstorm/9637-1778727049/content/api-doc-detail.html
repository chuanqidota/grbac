页面结构说明

左侧面板

  • 固定宽度 240px
  • 平铺展示所有对外接口
  • 每个接口显示：方法标签 + 路径 + 简短说明
  • 选中项高亮（蓝色左边框）

右侧面板

  • 接口详情：方法、路径、描述
  • 请求头文档（自动带入系统编码）
  • 请求参数文档
  • 响应示例（代码高亮）
  • 在线测试区（填写参数、发送请求、查看响应）
