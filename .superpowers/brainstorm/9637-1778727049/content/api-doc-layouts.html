API 文档页面布局方案

系统级页面，展示对外接口文档和测试功能

对外接口文档 共 5 个接口
GET /verify
验证 Token 有效性
GET /user-info
获取用户信息和角色
GET /menus
获取用户菜单
GET /permissions
获取用户权限列表
GET /validate-permission
校验接口权限

A. 卡片网格

每个接口一张卡片，点击展开详情和测试面板。视觉清晰，适合接口数量较少的场景。

对外接口文档
全部 GET POST
方法路径认证说明
GET /verify SystemCode + Token 验证 Token 有效性
GET /user-info SystemCode + Token 获取用户信息和角色
GET /menus SystemCode + Token 获取用户菜单
GET /validate-permission SystemCode + Token 校验接口权限

B. 表格 + 抽屉

表格列出所有接口，点击行打开抽屉查看详细文档和在线测试。与现有页面风格一致。

对外接口文档 共 5 个接口
GET /verify
GET /user-info
GET /menus
GET /permissions
GET /validate-permission
GET /api/external/verify

验证用户 Token 是否有效，返回用户身份信息

请求头
X-System-Code 必填
X-User-Token 必填
响应示例
{"code":0,"data":{"user_id":42,"username":"alice"}}

C. 左右分栏

左侧接口列表，右侧展示详情和测试。类似 Swagger UI 风格，信息密度高，适合多接口场景。
