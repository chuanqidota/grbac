新增能力：用户列表增加"查看详情"列 → 打开用户详情抽屉 → 查看该用户在各系统中的角色，可直接添加/移除角色

点击"添加角色"：弹出选择框，先选系统，再勾选该系统下的角色（支持多选）
点击角色标签的 ✕：直接移除该角色，二次确认
点击"查看权限"：展开显示该角色拥有的所有权限列表
★ 权限总览 — 角色 × 权限矩阵
可选增强：在角色管理页面增加"权限矩阵"Tab，以交叉表形式展示角色与权限的关系，一目了然

★ 快捷操作汇总
场景入口操作
给角色分配用户 角色管理 → 授权 → 分配用户 Tab 搜索用户 → 勾选 → 添加
给角色分配菜单和权限 角色管理 → 授权 → 分配菜单/权限 Tab 树形勾选菜单 / 表格勾选权限
查看某用户有哪些角色 用户管理 → 查看详情 抽屉展示用户在各系统的角色，可添加/移除
查看某用户最终权限 用户管理 → 查看详情 → 查看权限 展开显示该用户通过角色继承的所有权限
批量调整角色权限 角色管理 → 权限矩阵 Tab 交叉表直接 toggle，适合快速对比
查看某角色的用户 角色管理 → 授权 → 分配用户 Tab 左侧表格列出已分配用户
